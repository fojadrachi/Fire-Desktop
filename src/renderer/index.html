        Claude-Zugriff
        
            
        Gib Claude Code und anderen KI-Agenten per MCP Zugriff auf deine Server.

                ••••••••••••
                
                
                
              
        
              
        Port
        
            
        
            
        In Claude Code eintragen
        
            
        
              
              
            
        
            
        
              
            
        
            
        Danach Claude Code neu starten. Prüfen mit claude mcp list bzw. /mcp.
              Andere MCP-Clients: Streamable-HTTP-URL oben + Header Authorization: Bearer <Token>.
        
            
        
          
        

          
        
            
        Sicherheit
        
            
            
        Betrifft: Server stoppen/neu starten, Backup erstellen, Shell-Befehle, Dateien schreiben/löschen, Nginx neu laden.
              Der Server lauscht nur auf 127.0.0.1 – andere Rechner im Netz kommen nicht dran. Das Passwort deiner Server bekommt Claude nie zu sehen.
        
          
        
        
        

        
        
          
        
            
        Zugriff pro Server
        
            
        
            
        
              
        Nur lesen – Status, Konfiguration, Monitoring, Backups ansehen
        
              
        Steuern – zusätzlich Start/Stop/Neustart, Backups erstellen
        
              
        Voll (SSH) – zusätzlich Dateien lesen/schreiben, Shell-Befehle, Nginx
