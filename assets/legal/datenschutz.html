Datenschutzerklärung

Fire Desktop · Stand: 30. Oktober 2026
Kurz gesagt: Fire Desktop ist eine Desktop-App, die vollständig auf deinem Computer läuft. Es gibt keine Fire-Desktop-Server, keine Konten, keine Werbung, kein Tracking und keine Analyse. Daten werden nur an die Dienste übertragen, die du selbst einrichtest und benutzt (24fire, deine eigenen Server, optional Discord und Claude).

2. Welche Daten die App verarbeitet

  • API-Keys für die 24fire-API bzw. FireAPI, die du eingibst. Sie werden ausschließlich lokal in %APPDATA%\Fire Desktop\servers.json gespeichert und mit der Windows-Datenverschlüsselung (DPAPI) an dein Windows-Benutzerkonto gebunden.
  • Server-Daten, die über die 24fire-API abgerufen werden (Status, Konfiguration, IP-Adressen, Zugangsdaten, Monitoring, Traffic, Backups). Sie werden nur angezeigt und nicht dauerhaft gespeichert.
  • SSH-Fingerabdrücke deiner Server (zum Schutz vor Man-in-the-Middle-Angriffen) und, nach erfolgreicher Anmeldung, das SSH-Passwort – lokal und verschlüsselt gespeichert.
  • Einstellungen (Servernamen, Claude-Zugriff, Discord-Status), lokal gespeichert.

Fire Desktop erhebt keine Nutzungsstatistiken, Absturzberichte oder sonstige Telemetrie.

3. Datenübertragungen an Dritte

  • 24fire GmbH (api.24fire.de) bzw. FireAPI (live.fireapi.de): Die App sendet deine Anfragen mit deinem API-Key direkt an diese Schnittstellen, um deine Server zu verwalten. Es gilt die Datenschutzerklärung von 24fire.
  • GitHub: Die App fragt beim Start die neueste Version bei api.github.com ab und lädt Updates von GitHub. Dabei werden keine Daten aus der App übertragen; GitHub sieht technisch bedingt deine IP-Adresse.
  • Deine eigenen Server: Konsole, Dateimanager und Nginx-Verwaltung verbinden sich per SSH/SFTP direkt mit deinen Servern.
  • Discord (nur wenn du den Discord-Status einschaltest): Die App übergibt dem lokal laufenden Discord-Client die von dir gewählten Status-Texte (z. B. Servername, CPU-/RAM-Werte, Laufzeit). Discord zeigt diese in deinem Profil anderen Nutzern an. Es gilt die Datenschutzerklärung von Discord. Fire Desktop erhält dabei von Discord nur deinen Anzeigenamen zur Anzeige „Verbunden als …“ und speichert ihn nicht.
  • Claude / KI-Agenten (nur wenn du den Claude-Zugriff einschaltest): Die App stellt eine Schnittstelle ausschließlich auf deinem Rechner (127.0.0.1) bereit. Ein KI-Programm wie Claude Code, das du selbst verbindest, kann darüber Daten der von dir freigegebenen Server abrufen; diese Daten werden dann vom jeweiligen KI-Anbieter verarbeitet (bei Claude: Anthropic, siehe dessen Datenschutzerklärung). Server-Passwörter werden dabei nie weitergegeben.

4. Speicherdauer und Löschung

Alle Daten bleiben auf deinem Computer, bis du sie löschst – über „Server entfernen“ in der App oder durch Löschen des Ordners %APPDATA%\Fire Desktop. Das Aktivitätsprotokoll des Claude-Zugriffs wird nur im Arbeitsspeicher gehalten und beim Beenden verworfen.

5. Deine Rechte

Da Fire Desktop selbst keine personenbezogenen Daten auf eigenen Servern speichert, liegen alle Daten in deiner Verfügung. Du hast im Übrigen die Rechte aus der DSGVO (Auskunft, Berichtigung, Löschung, Einschränkung, Widerspruch, Beschwerde bei einer Aufsichtsbehörde). Für Daten bei 24fire, Discord oder Anthropic wende dich an den jeweiligen Anbieter.
